spaceComplexityExplanation: Nodes are rewired in place; only pointer variables are extra space.

## Summary

Use a dummy head and a moving tail pointer. Compare the two list heads, attach the smaller node, advance that list. Append any remaining nodes.

```python
class Solution:
    def mergeTwoLists(
        self, list1: ListNode | None, list2: ListNode | None
    ) -> ListNode | None:
        dummy = ListNode(0)
        tail = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next
            tail = tail.next
        tail.next = list1 if list1 else list2
        return dummy.next

```
